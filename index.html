Exportar backup

Baixa um arquivo .json com todos os dados atuais. Guarde esse arquivo — ele pode ser usado para restaurar ou para levar os dados a outro dispositivo.

Importar backup

Substitui todos os dados atuais deste navegador pelos dados do arquivo importado.
